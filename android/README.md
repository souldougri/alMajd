# Al Majd — تطبيق أندرويد (مجمع المجد) / Android WebView App

Minimal **Capacitor** Android wrapper around the school portal
`https://almadjdapp.vercel.app/` (the app opens directly on the portal welcome
screen, **not** the marketing site).

## What this app is

| Item | Value |
| --- | --- |
| App name | مجمع المجد / Al Majd |
| Package id | `com.almadjd.app` |
| Starts at | `https://almadjdapp.vercel.app/` |
| Splash | Navy (#14324D) + school logo + school name, then loads the URL |
| Status bar | Navy `#14324D` |
| Navigation | HTTPS on `almadjdapp.vercel.app` only; other hosts are blocked |
| Publish | Not published on Google Play (debug APK only) |

## Project layout

```
android/            native Android project (generated by Capacitor)
  app/src/main/res/  splash drawables + launcher icons (generated)
  app/src/main/java/com/almadjd/app/MainActivity.java
capacitor.config.ts  Capacitor configuration (app name, URL, splash, colors)
scripts/build-mobile-assets.mjs  regenerates splash + icon PNGs
```

Primary config lives in **`capacitor.config.ts`** at the repo root
(`server.url`, `appName`, splash/status-bar colors). The Android project is
synchronized from it with `npx cap sync android`.

## How to run from Android Studio

```bash
npm install
npx cap sync android
```

Then:

1. Open **Android Studio** → *Open* → select the `android/` folder in this repo.
2. Let Gradle sync finish (Android SDK + JDK 17 required; Android Studio will
   prompt to install the missing SDK components, including Android SDK
   Platform 36).
3. `Run ▸ Run 'app'` (⌃R) with an emulator or a physical device.
4. The app shows the splash for ~2.5 s and then loads the portal at
   `https://almadjdapp.vercel.app/`.

> The app loads the **live** portal from Vercel — no local web build is
> bundled. Rebuild + reinstall the APK if the portal changes.

## Building a debug APK

```bash
# From the repo root (first time only):
npx cap sync android

cd android
./gradlew assembleDebug
```

The APK is written to:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Install it on a device with:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

To change the URL / splash / colors, edit **`capacitor.config.ts`**, run
`npx cap sync android`, then rebuild.

## Regenerating splash + launcher images

```bash
node scripts/build-mobile-assets.mjs
npx cap sync android
```

Source art comes from `public/brand/logo.jpg`; the splash SVG template lives
inside `scripts/build-mobile-assets.mjs`.
